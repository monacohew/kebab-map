# Monaco's Kebab Map

Turkish kebab shops around New Zealand, tried and scored by Monaco. Visitors can make an account, add their own scores and comments, and compare with Monaco.

- Static site: `index.html`, `app.js`, `style.css`, `nz.json` (coastline), `vendor/` (Leaflet, MarkerCluster, supabase-js)
- Data and logins: Supabase project `kebab-map` (tables `shops`, `ratings`, `profiles`, view `shop_stats`)
- Hosting: GitHub Pages
